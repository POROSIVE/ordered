# O.R.D.E.R.E.D
Game about order

## disclaimer
the game is still in early development and isn't intended for public use, expect bug and unpolished experience oke

## installing the game
There's no executable release at the moment so either clone this repository or download it as .zip file and extract it from your download.
<br>
to run the game you need to have knowledge about running a godot project on (godot game engine)["https://godotengine.ord"]

## Controls
`w,a,s,d` key for moving
`left shift` for sprinting
`space` for jumping
`tab` for opening menu
